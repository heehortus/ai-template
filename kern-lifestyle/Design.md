# KERN — Design System

## 브랜드 컨셉
> "형태가 곧 태도다."

슬로우 패션 브랜드. 시즌을 초월한 구조적 실루엣과 자연 소재 중심의 의식적 소비를 지향한다.
에디토리얼 무드 — 여백, 대형 타이포, 오브젝트 플로팅, 커스텀 커서.

## 간격 스케일 (4배수 기준)

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 120 / 160px`

- 섹션 패딩: 데스크톱 `160px 0`, 모바일 `96px 0`
- 컨테이너 패딩: 데스크톱 `0 64px`, 모바일 `0 24px`
- GNB 패딩: `24px 48px`

## 인터랙션

| 요소 | 인터랙션 |
|---|---|
| 히어로 아이템 | 호버 → 커스텀 커서 `+ 시즌명`, 클릭 → 좌측 패널 슬라이드인 |
| 컬렉션 카드 | 호버 → 커스텀 커서, 클릭 → 좌측 패널 슬라이드인 |
| GNB | 기본: 로고+Menu 토글, 클릭: 필 메뉴 펼침 |
| 스크롤 진입 | IntersectionObserver → fade-up (translateY 32px → 0) |
| 뉴스레터 | 이메일 입력 후 구독 → 토스트 알림 |

## 섹션 구성

1. GNB — 로고 + 필 메뉴
2. Hero — 플로팅 컬렉션 오브젝트 + 대형 타이포
3. Collections — 시즌 그리드 (4장)
4. Philosophy — 에디토리얼 타이포 + 사진 그리드 + Our Story
5. Contact — 2단 분할 레이아웃
6. Footer — 3컬럼 + 뉴스레터
